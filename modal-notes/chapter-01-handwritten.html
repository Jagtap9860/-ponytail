0Primer — SDOF → modes 🔗

m·ẍ + c·ẋ + k·x = f(t)   →   fn = (1/2π)·√(k/m)

You know 1 mass → 1 peak. A plate/beam = many masses → many peaks. Each peak = one “hidden SDOF” = one mode. Ch.1 teaches you to see each one. 🔗
  • Resonance (SDOF) → every mode resonates in its own shape
  • Damping ζ → every mode gets its own damping
  • Messy time trace → FFT → FRF makes peaks obvious
§1.1 · the big picture

1What even IS modal analysis?

Cantilever logic: characteristics → + loads → response → + spec → pass/fail. Modal data is step-1 data: powerful, but can't judge alone!
  • 🖥️ Cabinet story: structural dynamics = full movie (all inputs → total chaos); modal = cast list. In frequency domain, chaos → clear peaks at the modes.
  • 📌 Modes = band-pass filters: response = Σ (mode filter × input). Starve a mode of input → tiny peak!
  • 🔬 Plate test: constant-force sine sweep → response breathes up/down → FFT → FRF with 4 peaks → dwell at each peak with 45 sensors → bend, twist, bend-2, twist-2 🎯
🍲 Cookbook: each loading “cooks” its own subset of modes.   🎻 Orchestra: total music hides the culprit — audition each mode separately!   🛝 Council bonus: swings — push in rhythm = resonance!
§1.2 · the money plot

2FRF = output ÷ input

H(f) = X(f) / F(f)   (complex! mag+phase ⟺ real+imag)

  • 3 push pts × 3 measure pts = 3×3 matrix hout,in (row = response, col = force)
  • 🎯 Drive point hii (push+measure same spot) — memorize: peak↔valley alternate · phase ∓180° · imag peaks same direction
  • 📌 Reciprocity: hij = hji → measure 1 row OR 1 column only!
⚠️ NODE RULE: reference on a mode's node ⇒ that mode vanishes from every FRF. Never park your reference on a node!!
§1.3 · hammer vs shaker

3Shaker vs Impact

🔨 roving hammer📳 shaker
Givesone ROW (response ref fixed)one COLUMN (force ref fixed)
Theoryidentical! (hij=hji)
Practicedouble hits, tip choicemass loading + stinger effects!
📌 Test article = structure + everything touching it (suspension, cables, sensors, shaker). 🧪 Roving-mass fix: leave all accels mounted or add dummy masses.
Analyzer chain 🏭: sensor → anti-alias filter → ADC (bits!) → window → FFT → avg spectra → FRF + coherence (0–1 = “% output explained by input”).
⚠️ LEAKAGE = villain #1: FFT thinks your record repeats forever — a cut-off wave smears everywhere. Windows = the tax you pay to stop it.
§1.4 + §1.5 · testing craft

4Impact 🔨 & shaker 📳 essentials

🔨 TIP = frequency knob: hard tip → wide band, soft → narrow. Good = flat spectrum + coherence ≈ 1. Rolloff + dying coherence up high? → tip too soft (or you just don't need those modes 😉).
🔨 Ringing past the record? → exponential window. Better cures first: narrower span / more lines (= longer record = natural decay ⏳).
📳 Best shaker inputs need NO window: Burst random (whole decay fits one record) + Sine chirp (repeats exactly). Plain random + Hanning = easy but still leaks a little 🍔.
✍️ Burst + Chirp = Bye-Ciao windows!
§1.6 · cheat sheet 🪟

5Windows — which, when?

WindowUse when…
Uniform (= none)signal fits record / periodic: impact-decayed, burst, chirp, stepped-sine
Hanning (bell)random / field data — forces ends → 0
Flat-toppure sine / calibration — amplitude accuracy!
Force + Exphammer pair: isolate pulse + decay the ringing tail
⚠️ Every window costs peak accuracy + fake extra damping. Still cheaper than leakage!
§1.7 · shapes from FRFs

6Peak-pick → curvefit

  • 6 pts → 36 FRFs. Read imag-peak heights: M1 ≈ [−1,−1,+1,+1,−1,−1] = bending; M2 = [+2,−2,0,0,−2,+2] = twist + node line 🎯
  • Peak-pick = great start; production = curvefitting:

measured FRF = Σ SDOF(modeᵢ) + residuals

Analyst sets 3 things: ① fit band ② # modes in it ③ residuals (out-of-band tug). ⚠️ Curvefit can't rescue bad FRFs — measure well first!!
§1.8 · don't confuse!

7Modal vs Operating data

📌 Operating data = response ONLY (forces unknown). response = FRF × force — FRF picks the dance, force picks the dancers.
  • Excite near M1 → shape ≈ M1 (+ whisper of M2) · midway → weird hybrid (M1+M2 mixed!)
  • 📌 ODS = Σ modes × force. Without force+FRF you can't see why — that's why we modal-test.
Modal dataOperating data
Givestrue f, ζ, shapes → SDM + simulation + FEM fixtrue in-service behavior
Can'tjudge pass/fail alonedo SDM/sim; shapes confuse
🗣️ Sofia: “Operating = where it hurts 🩹 · Modal = why + what to change 💊. Collect both!”
